# Playmakerz · PFE 2026.2 · Grupo 5

Site institucional da **Playmakerz**, centro de treinamento na Barra da Tijuca com duas marcas:

- **One to One Studio**: treino personalizado
- **PKZ Lab**: desenvolvimento de jovens atletas

O site apresenta as marcas e os planos e permite agendar uma aula experimental ou uma avaliação, com confirmação pelo WhatsApp.

## Páginas

| Arquivo | Página |
|---|---|
| `index.html` | Início |
| `planos.html` | Planos e pacotes |
| `one-to-one.html` | One to One Studio |
| `pkz.html` | PKZ Lab |
| `agendar-one-to-one.html` | Agendar aula experimental |
| `agendar-pkz.html` | Agendar avaliação |

Todas usam o mesmo `style.css` e `script.js`. As imagens ficam em `fotos/img/`.

## Tecnologias

HTML, CSS e JavaScript puros.
